# Electronics Fundamentals

A learning-focused electronics education app built with React, TypeScript, and TanStack Start.

## Development

You need Node.js and npm installed.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
